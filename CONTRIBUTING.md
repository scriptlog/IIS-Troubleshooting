# Contributing

Contributions are welcome! Please follow these guidelines:

1. **Fork** the repository.
2. **Create a branch** for your feature or bugfix.
3. **Test your changes** — ensure scripts run correctly on a Windows system with IIS.
4. **Submit a pull request** with a clear description of the changes.

## Style

- Keep both `.ps1` and `.bat` scripts in sync — changes should be reflected in both.
- Use descriptive variable names and comments where appropriate.
- Test as Administrator before submitting.
